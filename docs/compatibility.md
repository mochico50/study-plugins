## 前提と制約

- 対象は Claude（claude.ai と Claude Code）です。Codex や Cursor など、ほかのエージェント向けのマニフェストは置いていません
- Notion と Slack は、Claude 側でコネクタをつないでいる場合に使います。プラグインがコネクタを入れることはありません
- 保存先がチャットの場合、Claude は文書を次の会話に持ち越せません。進捗ページは、利用者が自分でプロジェクトのナレッジに保存して入れ替えます
- 試験情報は、資格ページを作った時点で公式ページから調べたものです。プラグインに試験情報や問題は含まれていません
- 練習環境（クラウドのアカウントなど）は利用者が用意します。プラグインがアカウントを作ったり、認証情報を扱ったりすることはありません
