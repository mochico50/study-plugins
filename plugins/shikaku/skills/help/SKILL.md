# 使い方の案内

shikaku で何ができるかと、いま何をすればよいかを、1画面で伝える。案内するだけで、ページやファイルは作らず、書き換えない。

## 手順

### 1. いまの状態を軽く調べる

最初に「いまの状態を確かめます。」と一言伝える。調べるのは次の3つだけにし、ページの中身は読み込まない。

1. 設定があるか（init スキルの「設定を探す」の順）
2. 設定があれば、記録の置き場所にある資格ページの一覧
3. 自分の進捗ページがあれば、その資格名と、完了チェック数 / 全チェック数

調べられなかった項目は「わかりません」と書き、推測で埋めない。

### 2. 下の型で出す

```markdown
shikaku は、資格の勉強を Claude が伴走するプラグインです。

**できること**

| やりたいこと | 頼み方 | コマンド |
|---|---|---|
| 最初の設定をする、設定を変える | 「資格の勉強の準備をしたい」 | `/shikaku:init` |
| 資格を調べる（試験の概要と学習の目安をまとめる） | 「◯◯の資格を調べたい」 | `/shikaku:research` |
| 自分のスケジュールを作る | 「◯◯の勉強を始めたい」 | `/shikaku:schedule` |
| 勉強する | 「はじめよう」「今日はここまで」 | `/shikaku:study` |
| 試験の直前の対策、受験後の振り返り | 「直前モード」「受けてきた」 | `/shikaku:study` |
| この案内を見る | 「shikaku の使い方を教えて」 | `/shikaku:help` |

ふだんは「頼み方」のように話しかければ動きます。

**いまの状態**

| 項目 | 状態 |
|---|---|
| 最初の設定 | 済み（記録は Notion に置いています） |
| 調べた資格 | ◯◯、△△ |
| 勉強中の資格 | ◯◯（12 / 40 項目） |

**次の一歩**

「はじめよう」と送ると、◯◯の今日のテーマから始められます。
```

「次の一歩」は、状態に合わせて1つだけ示す。

| 状態 | 次の一歩 |
|---|---|
| 設定がまだ | 「`/shikaku:init` で最初の設定をします。1分ほどで終わります。」 |
| 設定はあるが、調べた資格がない | 「『◯◯の資格を調べたい』と頼むと、試験の概要と学習の目安をまとめます。」 |
| 調べた資格はあるが、自分のスケジュールがない | 「『◯◯の勉強を始めたい』と頼むと、予定に合わせたスケジュールを作ります。」 |
| 勉強中の資格がある | 「『はじめよう』と送ると、今日のテーマから始められます。」資格ごとのプロジェクトやフォルダで勉強している場合は、そこで送るように添える |
| 受験目安まで14日以内 | 「試験が近いので、『直前モード』と送ると、模試と弱点の補強に切り替えます。」 |

### 3. 個別の質問には、その答えだけを返す

「計画から遅れたらどうなる？」「Notion なしでも使える？」のように、特定のことを聞かれたときは、一覧を出さずにその質問に短く答える。答えは該当するスキル（init、research、schedule、study）の内容をもとにし、書いていないことは「その機能はありません」と伝える。

## 守ること

- 1画面に収める。スキルの中身を長く説明し直さない
- 何も作らず、書き換えない。設定や記録を変えたいと言われたら、該当するスキルに進む
