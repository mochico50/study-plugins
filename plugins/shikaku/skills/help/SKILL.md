# 使い方の案内

shikaku で何ができるかを、1画面で説明する。何も調べず、何も作らず、書き換えない。設定や記録を読みに行かないので、すぐに返す。

## 一覧を出す

下の型のまま出す。前置きや補足の段落は足さない。

```markdown
shikaku は、資格の勉強を Claude が伴走するプラグインです。
試験を調べ、あなたの予定に合わせたスケジュールを作り、毎回の学習を同じ形で進めます。

**できること**

| やりたいこと | 頼み方 | コマンド |
|---|---|---|
| 最初の設定をする、設定を変える | 「資格の勉強の準備をしたい」 | `/shikaku:init` |
| 資格を調べる（試験の概要と学習の目安をまとめる） | 「◯◯の資格を調べたい」 | `/shikaku:research` |
| 自分のスケジュールを作る | 「◯◯の勉強を始めたい」 | `/shikaku:schedule` |
| 勉強する（解説、手を動かす課題、問題） | 「はじめよう」「今日はここまで」 | `/shikaku:study` |
| 試験の直前の対策、受験後の振り返り | 「直前モード」「受けてきた」 | `/shikaku:study` |
| いまの進み具合を見る（一緒に勉強している人の分も） | 「どこまでやったっけ」「全員の進捗」 | `/shikaku:status` |
| この案内を見る | 「shikaku の使い方を教えて」 | `/shikaku:help` |

ふだんは「頼み方」のように話しかければ動きます。

**はじめての場合**

1. `/shikaku:init` で最初の設定をする（1分ほど）
2. 「◯◯の資格を調べたい」と頼む
3. 「◯◯の勉強を始めたい」と頼む
4. 「はじめよう」で毎回の学習を始める
```

## 個別の質問には、その答えだけを返す

「計画から遅れたらどうなる？」「Notion なしでも使える？」のように、特定のことを聞かれたときは、一覧を出さずにその質問に短く答える。答えは該当するスキル（init、research、schedule、study、status）の内容をもとにし、書いていないことは「その機能はありません」と伝える。

## 守ること

- 1画面に収める。スキルの中身を長く説明し直さない
- 設定や記録を読みに行かない。いまの進み具合を聞かれたら、status スキルに進む
