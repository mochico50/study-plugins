# 自分の資格学習セットアップ

共用の資格ページ（試験情報と誰にでも当てはまる学習の目安）をもとに、本人の事情に合わせた具体的なスケジュールを引き、学習を始められる状態にする。学習の回し方は shikaku-gakushu スキルに任せる。

| 作るもの | 置き場所 |
|---|---|
| 進捗ページ「進捗：名前」（具体的なスケジュールとチェックボックス） | 資格ページの子ページ（Notion がなければファイルかチャット） |
| 知識book（分野ごとに1冊。任意） | アーティファクト |
| プロジェクトに貼る指示文 | 本人が新しいプロジェクトに貼る |

Claude プロジェクトの作成、指示文の貼り付け、コネクタの接続、練習環境のアカウント作成は本人が行う。Claude は案内だけする。

## 1. 状況を確かめる

まず保存先（Notion ／ ファイル ／ チャット）を決める。決め方と、保存先ごとの置き場所は shikaku-keikaku の「保存先」と同じ。すでに資格ページがあるなら、それと同じ保存先を使う。

その保存先で、その資格の資格ページと、自分の進捗ページを確認する。

| 状況 | やること |
|---|---|
| 資格ページがない | 先に shikaku-keikaku スキルの手順で資格ページを作る。できたら 2 へ |
| 資格ページはあり、自分の進捗ページがない | 2 へ |
| 自分の進捗ページもある | 新しく作らない。中身を確認し、スケジュールの引き直しか、足りない部分（知識book・指示文）だけかを聞く |

資格ページにチェックボックスが残っていたら、誰の進捗かを確かめ、その人の進捗ページへ移すことを提案する。移すのは了承を得てから。

## 2. 資格ページを読む

「学習の目安」（全体時間の幅、分野ごとの配分、進める順番）と「手を動かす課題の候補」を、スケジュールの土台にする。同じ資格を受ける他の人の進捗ページがあれば、参考にしてよいか聞く（読むだけで変えない）。

## 3. ヒアリングする

具体的なスケジュールを引くために、次を聞く。一度に全部並べず、2〜3回に分けてよい。他の資格プロジェクトの指示文や会話ですでにわかっていることは、確認だけにする。

日程
- 受ける人の名前（進捗ページのタイトルに使う。呼び名でよい）
- 開始日
- 受験したい時期。決まっていなければ、使える時間から逆算して提案する
- 平日・休日それぞれに使える時間と、勉強しやすい曜日や時間帯
- 学習できない・減る期間（旅行、行事、引っ越し、仕事の繁忙期など）
- 他に並行している資格学習があるか

経験
- 本人の前提：仕事の内容、触ったことのある技術
- 資格ページの分野ごとに、どれくらい知っているか（実務で使っている ／ 触ったことがある ／ 知らない）

進め方
- 練習環境をもう持っているか
- 使いたい教材や学び方の好み（公式コース、問題集、手を動かすのが中心、など）
- 学習の報告を Slack に投稿するか（任意）。投稿するならチャンネル名か ID。一緒に勉強する人や見守ってくれる人がいるときに向く。いらなければ「なし」

## 4. スケジュールを引いて確認する

1. 使える時間の合計を出す（週ごとの時間 × 週数。学習できない期間は引く）
2. 資格ページの目安時間を、本人の経験で調整する。実務で使っている分野は短く、知らない分野は厚くする
3. 1 と 2 を比べる。足りなければ、受験を後ろにずらす ／ 週の時間を増やす ／ 重点分野に絞る、の選択肢を示して本人に選んでもらう
4. 週（または2週）ごとに、やる分野・課題・目安時間を割り当てる。学習が減る週は軽くし、前後で取り返す。最後の1〜2週は模試と弱点の補強にあて、受験予約の時期も入れる
5. 手を動かす課題は、資格ページの候補から経験と時間に合わせて選ぶ
6. この案を表で見せて、本人の確認を得てから書き込む

## 5. 進捗ページ「進捗：名前」を作る

資格ページの子ページとして作る（ファイルの場合は資格ページと同じフォルダの `shinchoku-<名前>.md`、チャットの場合は Markdown の文書）。入れるもの：

1. 本人の経験から見た一言（何が活きて、どこを補強するか）
2. 開始日と受験目安、週の学習時間、予定上の注意（学習が減る週など）
3. 学習プラン：週ごとの見出し（期間・テーマ・目安時間）の下に `- [ ]` チェックボックス
4. 手を動かす課題：`- [ ] 課題 n：…` の形で番号付き、末尾に関係する分野を添える

守ること：

- やることはすべてチェックボックスにする。説明文や「課題 2〜5」のような参照はチェックボックスにしない
- 課題は練習環境で完結し、最後に削除できるものにする
- 共用の資格ページと、他の人の進捗ページは変えない

## 6. 知識book を用意する（任意）

知識book は、学んだ用語や構成を分野ごとにためていく自分用のまとめ。アーティファクトが使える環境で、本人が欲しいときに用意する。

- すでにある：その URL を使う
- ない：新しく作る。用語と構成を図つきで、初学者にもわかる形にし、あとから追記しやすい構成にする
- いらない・作れない環境：作らない。指示文の知識book の行は「なし」にする

## 7. 指示文を出し、最後に案内する

下のテンプレートの【】を埋め、そのまま貼れる形でコードブロックにして出す。

```markdown
# 【資格名（試験コード）】学習プロジェクト
このプロジェクトでは、【名前】の【資格名】合格に向けた学習を Claude が伴走する。このプロジェクトはこの資格専用。学習の始め方・進め方・終わり方は shikaku-gakushu スキルに従う。

## 本人の前提
- 【仕事の内容、触ったことのある技術、まだ知らない分野】
- 学習時間は【平日◯時間・休日◯時間、週◯時間前後】

## この資格
- 資格名：【資格名（試験コード）】
- 保存先：【Notion ／ ファイル ／ チャット】
- 資格マップ：【URL。Notion 以外なら「なし」】
- 資格ページ：【URL、またはファイルの場所】
- 進捗ページ：【URL、またはファイルの場所】
- 知識book：【「名前」と URL ／ なし】
- 練習環境：【例：個人の AWS アカウント】
- 報告先：【Slack のチャンネル名か ID ／ なし】
```

案内：

1. claude.ai で新しいプロジェクトを作る。名前は「資格: ◯◯」（Claude Code で使う場合は、その資格用のフォルダを作り、指示文を `CLAUDE.md` に置く）
2. プロジェクトの指示に、出した指示文を貼る。保存先がチャットの場合は、資格ページと進捗ページの文書をプロジェクトのナレッジにも入れる
3. 練習環境がまだなければ作る（アカウント作成とログインは本人。パスワードやアクセスキーは Claude に渡さない）
4. プロジェクト内で新しいチャットを開き「はじめよう」と送る。進捗が「0 / 全項目数」で出れば完了
