# 初回の設定

資格の勉強で毎回使う設定を、最初に1回だけ決めて書き残す。research、schedule、study の各スキルはこの設定を読んで動くので、資格を増やしても同じことを聞かずに済む。

このスキルの中では、決めることを次の言葉で呼ぶ。本人に話すときは、手順の型にある言い方（「学習の記録を置く場所」など）を使う。

| 決めること | 中身 |
|---|---|
| 保存先 | 学習の記録（資格ページと進捗ページ）を置く場所。Notion ／ ファイル ／ チャット |
| 資格マップ | 資格ページを並べる親ページ（保存先が Notion のときだけ） |
| 受ける人 | 進捗ページのタイトルに使う名前。呼び名でよい |
| 報告先 | 学習の報告を投稿する Slack のチャンネル。いらなければ「なし」 |

## 設定の置き場所

| 保存先 | 設定を書く場所 |
|---|---|
| Notion | 資格マップのページの先頭に「shikaku の設定」の節 |
| ファイル | `shikaku/settings.md` |
| チャット | 書き残せない。設定の文面を出し、本人がプロジェクトの指示に貼る |

書く形はどの保存先でも同じ。

```markdown
## shikaku の設定
- 保存先：【Notion ／ ファイル ／ チャット】
- 受ける人：
  - 【名前】（報告先：【Slack のチャンネル名か ID ／ なし】）
- 設定した日：【2026-01-15 の形】
```

複数人で同じ資格マップを使うときは、「受ける人」に1人1行ずつ足す。

## 設定を探す（ほかのスキルもこの順で探す）

1. プロジェクトの指示文に「保存先」の行があれば、その指示文の内容を設定として使う
2. 作業フォルダに `shikaku/settings.md` があれば、それを読む
3. Notion がつながっていれば、「資格マップ」を検索し、そのページの「shikaku の設定」を読む
4. どれもなければ、設定はまだない

本人がその場で指定したこと（例：「保存先はファイルで」）は、書き残した設定より優先する。設定そのものを変えたいのか、今回だけなのかがわからなければ聞く。

## 手順

本人に見える文は、すべて日本語で書く。調べている途中の独り言は書かず、型にある文だけを出す。

調べる → いまの状態を見せる → 決めることを聞く → 書く、の順で進める。本人が「何と返せば終わるか」をひと目でわかるようにする。

### 1. 何をするかを説明してから、調べる

本人は、shikaku が何をするものか、なぜ設定がいるのかをまだ知らない。最初に下の型で説明する。「保存先」のような shikaku の中の言葉は使わず、何を置く場所なのかを書く。

```markdown
shikaku は、資格の勉強を Claude が伴走するプラグインです。
勉強を始める前に、次の3つを決めます。1分ほどで終わります。

| 決めること | 何のためか |
|---|---|
| 学習の記録を置く場所 | 資格の情報（試験の概要や学習の目安）と、あなたの進み具合（スケジュールとチェックリスト）を書き残します。次に開いたとき、続きから始めるためです。Notion か、このフォルダのファイルを選べます |
| あなたの名前 | 進み具合のページに名前をつけます。家族やチームで一緒に使っても、記録が混ざらないようにするためです |
| 学習の報告先 | 学習した日に、まとめを Slack に投稿できます。一緒に勉強する人がいるとき向けで、なくても使えます |

まず、いまの環境を調べます（Notion と Slack がつながっているか、すでに記録があるか）。
```

設定がすでにある人が呼んだときは、この説明を「いまの設定を確かめます。」の1行に置き換える。

調べること：

- 設定がすでにあるか（「設定を探す」の順）
- Notion のコネクタがつながっているか。つながっていれば「資格マップ」があるか
- 作業フォルダにファイルを書けるか
- Slack のコネクタがつながっているか

ここでは調べるだけで、ページやファイルは作らない。

### 2. いまの状態と、決めることを見せる

下の型で出す。前置きや説明の段落は足さない。

```markdown
**いまの環境**

| 項目 | 状態 |
|---|---|
| これまでの設定 | まだありません |
| Notion | つながっています。資格のページがすでにあります（「資格マップ」） |
| このフォルダ | ファイルを書けます |
| Slack | つながっています |

**決めること**

| # | 決めること | おすすめ | 理由 |
|---|---|---|---|
| 1 | 学習の記録を置く場所 | Notion | すでに資格のページがあるので、そこに続けて書けます |
| 2 | あなたの名前 | ◯◯ | すでにある進み具合のページの名前です |
| 3 | 学習の報告先 | なし | あとから足せます |

このままでよければ「OK」と返してください。
変えたいところは「1 はファイル、3 は #study」のように、番号で教えてください。
```

型の決まり：

- 「いまの環境」は1項目1行で、事実だけを書く
- 「決めること」は、おすすめを必ず1つに絞り、理由を一言添える。「どちらにしますか」と選ばせる書き方にしない
  - 記録を置く場所：Notion がつながっていれば Notion、なければファイル、どちらもなければチャット
  - 名前：すでにある進捗ページなどからわかればその名前。わからなければ「（教えてください）」
  - 報告先：すでに使っているチャンネルがわかればそれ。わからなければ「なし」
- 「（教えてください）」が残っているときは、最後の案内を「2 の名前を教えてください。ほかはこのままでよければ、名前だけ返してください。」のように、返すものを名指しする
- 補足が必要なときだけ、表の下に1行ずつ足す。足してよいのは次のものだけ
  - 記録を置く場所がチャットになる場合：「Notion もファイルも使えないため、記録はこの会話に文書として出します。次回に続けるには、その文書をご自身で保存し直す必要があります。」
  - Notion や Slack がつながっていない場合：「Notion を使いたい場合は、Claude の設定でコネクタをつないでから、もう一度 `/shikaku:init` を呼んでください。」つなぐのは本人で、Claude は代わりにつながない
  - ほかの人と使えること：「ほかの人と一緒に使う場合は、その人の名前も教えてください。」
- 設定がすでにある場合は、「決めること」の表を「いまの設定」の表（おすすめの列を「いまの設定」に、理由の列はなし）に変えて、同じ案内（OK か、番号で変更）で締める

### 3. 返事を受けて、書く

- 「OK」「おまかせ」：おすすめのとおりにする
- 番号での変更：その項目だけ変える。変更によって新しく決めることが出たときだけ、1回聞き直す（例：保存先を Notion にしたが資格マップがない → どこに作るかを聞く）

保存先が Notion で資格マップがまだないときは、どこに作るかを聞いて「資格マップ」というページを作る。会話に URL があれば、それを使う。

もう一度確認を挟まず、「設定の置き場所」のとおりに書く。保存先がファイルで `shikaku/` フォルダがなければ作る。

### 4. 終わったと伝える

下の型で出す。

```markdown
設定が終わりました。

| 項目 | 設定 |
|---|---|
| 学習の記録を置く場所 | Notion（「資格マップ」の下） |
| あなたの名前 | ◯◯ |
| 学習の報告先 | なし |

この設定は、Notion の「資格マップ」の先頭に書いてあります。変えたいときは、また `/shikaku:init` を呼んでください。

次にできること：
- 「◯◯の資格を調べたい」：試験の概要と学習の目安をまとめたページを作ります
- 「◯◯の勉強を始めたい」：あなたの予定に合わせたスケジュールを作ります
```

ほかのスキルの途中でここに来た場合は、「次にできること」を省き、元の依頼にそのまま戻る。

## 守ること

- 聞くのは手順 2 の1回で済ませる。設定のために何度も往復しない
- 設定がないことを理由に、頼まれたことを断らない。その場で手順 1〜3 を済ませて続ける
- パスワードやトークンは聞かず、受け取らない。コネクタの接続は Claude の設定画面で本人が行う
- 保存先を変えるとき、すでにある資格ページや進捗ページは勝手に移さない。移すかどうかを聞き、移すなら元を残したまま写して、本人が確かめてから元を片付ける
