# 初回の設定

資格の勉強で毎回使う設定を、最初に1回だけ決めて書き残す。research、schedule、study の各スキルはこの設定を読んで動くので、資格を増やしても同じことを聞かずに済む。

| 決めること | 中身 |
|---|---|
| 保存先 | 資格ページと進捗ページを置く場所。Notion ／ ファイル ／ チャット |
| 資格マップ | 資格ページを並べる親ページ（保存先が Notion のときだけ） |
| 受ける人 | 進捗ページのタイトルに使う名前。呼び名でよい |
| 報告先 | 学習の報告を投稿する Slack のチャンネル。いらなければ「なし」 |

## 設定の置き場所

| 保存先 | 設定を書く場所 |
|---|---|
| Notion | 資格マップのページの先頭に「shikaku の設定」の節 |
| ファイル | `shikaku/settings.md` |
| チャット | 書き残せない。設定の文面を出し、本人がプロジェクトの指示に貼る |

書く形はどの保存先でも同じ。

```markdown
## shikaku の設定
- 保存先：【Notion ／ ファイル ／ チャット】
- 受ける人：
  - 【名前】（報告先：【Slack のチャンネル名か ID ／ なし】）
- 設定した日：【2026-01-15 の形】
```

複数人で同じ資格マップを使うときは、「受ける人」に1人1行ずつ足す。

## 設定を探す（ほかのスキルもこの順で探す）

1. プロジェクトの指示文に「保存先」の行があれば、その指示文の内容を設定として使う
2. 作業フォルダに `shikaku/settings.md` があれば、それを読む
3. Notion がつながっていれば、「資格マップ」を検索し、そのページの「shikaku の設定」を読む
4. どれもなければ、設定はまだない

本人がその場で指定したこと（例：「保存先はファイルで」）は、書き残した設定より優先する。設定そのものを変えたいのか、今回だけなのかがわからなければ聞く。

## 手順

### 1. いまの状態を確かめる

上の順で設定を探す。

- すでにある：内容を見せ、何を変えたいかを聞く。変えるところだけ聞き直す
- 設定はないが、資格マップや `shikaku/` フォルダがすでにある：それを使ってよいかを確かめ、足りない項目だけ聞く
- 何もない：2 へ

### 2. 使える道具を確かめる

Notion のコネクタがつながっているか、作業フォルダにファイルを書けるか、Slack のコネクタがつながっているかを確かめる。ここでは確かめるだけで、ページやファイルはまだ作らない。

### 3. 聞く

次の3つを一度に聞く。それぞれに、2 の結果から見たおすすめを添える。「おまかせ」と言われたら、おすすめのとおりにする。

1. 保存先：Notion がつながっていれば Notion、なければファイル、どちらもなければチャットをおすすめにする。チャットは、進捗ページを本人が毎回入れ替える手間があることを伝える
2. 受ける人の名前：呼び名でよい。ほかの人と一緒に使うかも聞く
3. 学習の報告：Slack に投稿するか。投稿するならチャンネル。一緒に勉強する人や見守ってくれる人がいるときに向く。いらなければ「なし」

コネクタについては、案内を一言添えるだけにする。

- Notion や Slack を使いたいのにつながっていないとき：「Claude の設定で Notion（Slack）のコネクタをつないでください。つないだら、もう一度声をかけてください」と伝える。つなぐのは本人で、Claude は代わりにつながない
- すぐ始めたい人には、いまはファイルかチャットで始めて、あとで保存先を変えられると伝える

保存先が Notion のときは、資格マップの場所も決める。

1. 会話に URL があれば、それを使う
2. なければ Notion を「資格マップ」で検索し、見つかったページを使ってよいか確かめる
3. 見つからなければ、どこに作るかを聞き、「資格マップ」というページを新しく作る

### 4. 書き残す

決めた内容を短く見せて確認してから、「設定の置き場所」のとおりに書く。保存先がファイルで `shikaku/` フォルダがなければ作る。

### 5. 次の一歩を案内する

- 自分から init を呼んだ人には、次にできることを1〜2行で伝える：「◯◯の資格を調べたい」（research）、「◯◯の勉強を始めたい」（schedule）
- ほかのスキルの途中でここに来た場合は、案内を挟まず、元の依頼にそのまま戻る

## 守ること

- 質問は 3 の1回で済ませる。設定のために何度も往復しない
- 設定がないことを理由に、頼まれたことを断らない。その場で 2〜4 を済ませて続ける
- パスワードやトークンは聞かず、受け取らない。コネクタの接続は Claude の設定画面で本人が行う
- 保存先を変えるとき、すでにある資格ページや進捗ページは勝手に移さない。移すかどうかを聞き、移すなら元を残したまま写して、本人が確かめてから元を片付ける
